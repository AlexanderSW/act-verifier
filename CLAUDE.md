# Правила для Claude Code в цьому репозиторії

## Що це
Верифікатор актів КБ-2в / КБ-3. Каталог перевірок і статусів — docs/checks.md. Еталони — tests/fixtures/*/expected.json.

## Правила
- Гроші й обсяги — тільки `Decimal`. Ніякого float в арифметиці.
- Числа беруться лише з файлів. Не вигадувати й не підставляти значення «за змістом».
- Бракує даних → статус `unknown`, ніколи не `pass`.
- Не змінювати `expected.json` і xlsx у tests/fixtures вручну, щоб тест «пройшов». Фікстури змінюються тільки через `scripts/generate_fixtures.py`, і з поясненням чому.
- Верифікатор лише читає вхідні файли. Нічого в них не записує.
- Кожен звіт закінчується блоком доказів: що перевірено, що ні, звідки числа.

## Як перевіряти свою роботу
```bash
pytest -q
```
Готово = усі сценарії в test_verifier.py зелені (не xfail) і test_fixtures_integrity.py зелений.
Наприкінці відповіді писати, які тести запускав і що вони показали.
Середовище: Windows, Git Bash. Тести запускати так:
.venv/Scripts/python -m pytest -q
Очікуваний стан після реалізації: 213 passed, 0 xfailed, 0 failed (xfail знято: 21 сценарій зелений — T11 cli-verifier).
